# HR-Workforce-Analytics-Dashboard-Power-BI
Power BI HR &amp; Workforce Analytics Dashboard for analyzing employee attrition, performance, salary, satisfaction, and workforce trends. 


📌 Project Overview
This project presents an interactive HR & Workforce Analytics Dashboard built using Microsoft Power BI. The dashboard analyzes 500 employee records across 15 attributes to provide insights into workforce structure, employee attrition, salary, performance, satisfaction, and training.

The project covers the complete analytics workflow, from data cleaning and transformation to DAX calculations, KPI development, and interactive data visualization.


 🎯 Project Objectives
- Analyze overall employee headcount and workforce structure.
- Monitor employee attrition and identify high-attrition groups.
- Analyze average salary and employee performance.
- Evaluate employee satisfaction and training hours.
- Compare workforce metrics across departments, employee levels, and tenure groups.
- Provide interactive HR insights to support data-driven decision-making.

 🔄 Data Preparation
Power Query was used to clean and transform the raw HR dataset before analysis.

Key transformations included:

- Data cleaning and standardization
- Data type transformation
- Creating Tenure Buckets
- Creating Age Groups
- Creating an Active Flag
- Preparing the dataset for analysis and visualization


🧮 DAX & KPI Analysis
DAX measures were created to calculate key HR metrics, including:

- Headcount
- Attrition Rate
- Average Salary
- Average Performance
- Average Training Hours
- Satisfaction Score

The dashboard includes 6 KPI cards benchmarked against defined SME targets.


📊 Dashboard Features
The dashboard provides:

- Interactive KPI cards

- Employee-level analysis
- Tenure-based analysis
- Performance analysis
- Salary analysis
- Interactive slicers
- Drill-down analysis

## Interactive Filters

Users can filter the dashboard using:

- Department
- Employee Level

🔍 Key Insights
The analysis identified the following workforce trends:

- Overall attrition rate: 19.6%
- Engineering and Sales showed approximately 25% attrition.
- Employees with 0–2 years of tenure showed a 24.4% attrition rate.

These findings help identify workforce segments that may require further HR analysis and attention.
